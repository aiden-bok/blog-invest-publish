# 원금 보존 연구소 (배포 저장소)

<https://invest.route50.kr/> 블로그의 배포 결과물을 두는 저장소입니다.

원금을 지키며 자산을 불리는 방법을 찾는 주식·부동산 공부 기록을 [Hugo](https://gohugo.io/)와 [PaperMod](https://github.com/adityatelange/hugo-PaperMod) 테마로 만들어 GitHub Pages로 공개합니다.
